# Staff Tracker using Spring MVC

Staff Tracker is a CRUD (Create, Read, Update, Delete) application built with Spring MVC, Java, JDBC, HTML, and CSS. It allows you to manage staff records efficiently through a simple web interface.

## Table of Contents

- [Features](#features)
- [Tech Stack](#tech-stack)
- [Installation](#installation)
- [Usage](#usage)
  


## Features

- Add new staff members
- View all staff details
- Update existing staff information
- Delete staff records
  

## Tech Stack

- *Frontend*: HTML, CSS
- *Backend*: Java (Spring MVC)
- *Database*: MySQL
 *Server*: Apache Tomcat
- *IDE*: Eclipse

  ## Dependencies

1.spring-webmvc
2.spring-context
3.spring-jdbc
4.mysql-connector-java
5.jstl
6.javax-servlet

  
## Installation

Follow these steps to set up the project locally:

1. *Clone the repository*
   ```bash
   git clone https://github.com/Ojasvi-Kanathe/staff-tracker-springmvc.git

2. Import the project into Eclipse

Open Eclipse

Go to File > Import > Existing Maven Projects

Browse to the cloned repository and import it

 
3. Configure Tomcat server

Add Apache Tomcat to your Eclipse server runtime environments

Right-click on the project > Run As > Run on Server



4. Database setup

Install MySQL

Create a database 

Import the schema and tables 

Configure database credentials in your project’s JDBC config file



## Usage

Start the server via Eclipse

Use the interface to add, update, delete, and view staff data
